*** Mazaady Task ***
* How to run the project
1- Clone the project through clone "gh repo clone mohammedgado/ios-mazaady" command or download the zip file
2- Open the project with XCode through opening the file ".xcworkspace"
3- Run the project through selecting from the toolbar "Product-> Run"
